# lib/ - JDBC Driver Directory

Place the MySQL JDBC connector JAR here before building:

  mysql-connector-j-8.0.33.jar

Download URL:
  https://dev.mysql.com/downloads/connector/j/

Steps:
1. Go to the URL above
2. Select "Platform Independent" from the OS dropdown
3. Download the ZIP archive
4. Extract and copy `mysql-connector-j-8.0.33.jar` into this folder
