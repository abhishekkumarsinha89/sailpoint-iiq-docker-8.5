# src/ - SailPoint IIQ Binary Directory

Place your SailPoint IdentityIQ zip file here before building:

  identityiq-<version>.zip  (e.g., identityiq-8.4.zip)

Download from: https://compass.sailpoint.com
  → Downloads → IdentityIQ → <your version>

NOTE: SailPoint IIQ binaries are proprietary and require a valid
      SailPoint customer or partner login to download. This project
      does NOT include any SailPoint software.
